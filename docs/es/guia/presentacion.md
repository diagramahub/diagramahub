# Modo presentación

El modo presentación oculta la barra de herramientas del editor y la barra lateral de la aplicación para que el diagrama ocupe la ventana, ideal para revisarlo en una reunión o proyectarlo.

## Entrar y salir

- Pulsa **Presentar** en la barra superior del editor.
- Para salir, pulsa ++esc++ o el botón de cerrar (**Salir de pantalla completa (Esc)**) en la esquina.

Al entrar, la barra lateral de la aplicación se oculta automáticamente y vuelve a aparecer al salir. Un indicador **Modo Presentación · Presiona Esc para salir** te recuerda cómo volver.

## Controles

Durante la presentación tienes controles flotantes de zoom:

| Control | Acción |
|---|---|
| **Reducir zoom** / **Aumentar zoom** | Aleja o acerca el diagrama; el porcentaje actual se muestra entre ambos |
| **Ajustar a pantalla** | Encaja el diagrama completo en la ventana |

También puedes usar la rueda del ratón para el zoom y arrastrar el diagrama para moverlo.

!!! tip "Prepara la vista antes de presentar"
    Cierra los paneles que no necesites (código, descripción, chat) antes de entrar. El zoom y la posición se guardan con cada diagrama. Deja el diagrama encuadrado como quieras mostrarlo y así se abrirá la próxima vez. Para un fondo limpio en pantalla, elige el color y el patrón en **Apariencia** (ver [El editor](editor.md#apariencia)).

## Presentar sin abrir el editor

Si quieres mostrar un diagrama a personas sin cuenta, crea un enlace con **Compartir diagrama**: la vista compartida es de solo lectura. Consulta [Compartir diagramas](compartir.md).
