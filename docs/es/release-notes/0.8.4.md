# 0.8.4 (2026-10-19)

Correcciones de seguridad y configuración, y documentación completa en el sitio publicado: además de la instalación y las notas de versión, ahora hay guía de uso, operación self-host, desarrollo y seguridad, en español e inglés, verificadas contra el código. Al escribir esa documentación contra el código aparecieron los fallos que corrige esta versión. Sin funciones nuevas.

## ⬆️ Notas de actualización

- **Actualiza pronto**: incluye correcciones de seguridad (chat de IA, inicio de sesión con MFA, webhooks de Stripe y renderizado de Mermaid).
- Reconstruye las imágenes (`docker compose up -d --build`): `start.sh` cambió y va dentro de la imagen.
- Sin migraciones manuales. Se crea sola la colección `mfa_token_attempts` (con expiración automática) y los eventos de webhook existentes siguen siendo válidos.
- **Detrás de un reverse proxy**, define `FORWARDED_ALLOW_IPS` con la IP o red de tu proxy para que los límites de peticiones y el registro de auditoría vean la IP real del cliente. Ver [Producción](../self-host/produccion.md). No uses `*`.
- **No cambies tu `AI_ENCRYPTION_KEY`** si ya tienes una: cifra las keys de IA, los secretos de las integraciones y los secretos TOTP. El instalador ahora la genera en instalaciones nuevas y conserva la existente.
- Si tu `backend/.env` trae `BACKEND_CORS_ORIGINS` como lista JSON, ya funciona; el formato recomendado es separado por comas.
- Un webhook de Stripe que falla al procesarse ahora responde 500 (antes 200) para que Stripe lo reintente.

## 🔒 Seguridad

- **Chat de IA: cada sesión es solo de su dueño.** Seis endpoints de `/chat-sessions/{id}` (ver, renombrar, borrar, cambiar modelo, borrar mensaje y cambiar su estado) no pedían sesión ni comprobaban el dueño, y enviar un mensaje no comprobaba que la sesión fuera tuya. Ahora todas las rutas del chat piden sesión y responden 404 ante una sesión ajena o un mensaje de otra sesión.
- **`POST /ai/test-provider` pide sesión.**
- **Webhooks de Stripe idempotentes de verdad.** El manejador usaba el id del objeto en lugar del id del evento y no registraba nada. Ahora cada evento se reclama por su `event.id` (índice único): un duplicado no se reaplica, un fallo libera el reclamo para que Stripe reintente, y un reclamo abandonado se retoma a los 10 minutos.
- **Inicio de sesión con MFA: límite de 5 intentos por token temporal.** El contador nunca se incrementaba. Ahora el intento se reserva de forma atómica antes de verificar el código (también con peticiones simultáneas), el token es de un solo uso tras un inicio exitoso y alcanzar el límite queda en el registro de auditoría (`login_failed`, `mfa_max_attempts`).
- **Mermaid en modo `strict`.** Con `loose`, las etiquetas HTML de un diagrama no se saneaban mientras Mermaid lo dibujaba, antes de que el SVG llegara a la página (también en enlaces compartidos). Ahora pasan por DOMPurify durante el render.
- **IP real del cliente detrás de un proxy.** Nueva variable `FORWARDED_ALLOW_IPS` (por defecto solo localhost): `X-Forwarded-For` solo se acepta de esas direcciones. Antes, detrás de un proxy todos los usuarios compartían la IP del proxy en los límites de peticiones, el bloqueo de cuentas y la auditoría.
- **Límite de enlaces compartidos** con el limitador común, que purga las IPs viejas (antes las guardaba para siempre), y respuesta 429 con `Retry-After`.

## 🔧 Correcciones

- **CORS**: las plantillas traían `BACKEND_CORS_ORIGINS` como lista JSON y el backend lo convertía en orígenes inválidos. Se aceptan ambos formatos.
- **Modo `external-mongodb`**: el backend escuchaba en el puerto 8000 mientras el compose publicaba el 5172.
- **Instalador**: genera `AI_ENCRYPTION_KEY`, sin la cual fallaban la IA, las integraciones y el TOTP.
- **Plantillas de entorno**: sin `VERSION=1.0.0` (sobrescribía la versión real), `SENTRY_DSN` vacío (un valor de ejemplo activaba Sentry) y `FRONTEND_URL` en el puerto 5173. `ACCESS_TOKEN_EXPIRE_MINUTES` no tiene efecto y se documenta así.
- **Asistente de instalación**: pedía 8 caracteres sin carácter especial; ahora aplica la política real (12, mayúscula, minúscula, dígito y carácter especial). El frontend ya no acepta el acento grave como carácter especial, que el servidor rechazaba.
- `STRIPE_QUICKSTART.md` y los README de despliegue (Kroki) actualizados.

- **Inicio corregido.** Listaba solo Mermaid y PlantUML, cuatro proveedores de IA y funciones que no existen (anotaciones en presentación, autocompletado, historial de prompts como función de usuario); ahora refleja el producto 0.8.x.
- La guía de instalación incluye Kroki en ambos modos de despliegue y aclara que `AI_ENCRYPTION_KEY` es necesaria.
- Más extensiones de Material: pestañas de contenido, teclas, listas de tareas, migas de pan y botón «editar esta página».
- `SECURITY.md` y `AGENTS.md` alineados con el código.
