# 0.5.11 (2026-07-19)

Mejoras de seguridad y reproducibilidad, junto con información más clara de uso en administración y visibilidad de releases en la aplicación.

## ✨ Funcionalidades

- La tabla de gestión de usuarios ahora muestra los diagramas de cada usuario agrupados por motor: Mermaid, PlantUML, D2 y DBML.
- La página Acerca de muestra la versión de la aplicación en ejecución e incluye un enlace directo a la página de releases en GitHub.

## ⬆️ Actualizaciones

- Se agregó el archivo versionado `poetry.lock` del backend y el build Docker ahora instala las dependencias bloqueadas.
- Se actualizó la imagen base del backend a Python 3.13 sobre Alpine 3.23.
- Se fijaron versiones reproducibles para las dependencias de documentación y se actualizaron los comandos de instalación.

## 🔒 Seguridad

- Se actualizaron `cryptography` a 46.0.7, `gunicorn` a 23.0.0 y `python-multipart` a 0.0.31.
