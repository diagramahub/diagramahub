# 0.5.2 (2026-05-10)

Release de seguridad: actualización de dependencias frontend para resolver vulnerabilidades críticas y altas reportadas por Snyk bajo el programa Secure Developer para Open Source.

## ⬆️ Upgrades

- **axios**: 1.12.2 → 1.16.0 (corrige 2 vulnerabilidades críticas, 5 altas y 5 medias: Prototype Pollution, HTTP Response Splitting, SSRF, información sensible en headers).
- **jspdf**: 2.5.2 → 4.2.1 (corrige 1 vulnerabilidad crítica, 7 altas y 2 medias: control externo de archivo, encoding de salida, uso ilimitado de recursos, ReDoS).
- **react-router-dom**: 7.9.4 → 7.15.0 (corrige 2 vulnerabilidades altas y 2 medias: XSS, Open Redirect, CSRF).
- **mermaid**: 11.4.1 → 11.14.0 (corrige vulnerabilidades en dependencias transitivas: dompurify XSS, lodash-es Prototype Pollution, dagre-d3-es Prototype Pollution, uuid validación de entrada).
- **easymde**: 2.18.0 → 2.21.0 (corrige vulnerabilidad ReDoS en codemirror transitivo).

## 🐛 Fixes

- Versión de la aplicación corregida en `backend/app/core/config.py`: mostraba `1.0.0` incorrectamente, ahora refleja `0.5.2`.

## 🔧 Internal

- Integración con **Snyk Secure Developer Program for Open Source** para monitoreo continuo de vulnerabilidades.
- Badge de Snyk agregado al README.md con estado de vulnerabilidades conocidas.
- Actualizada versión en todos los archivos del repositorio (`CLAUDE.md`, `VERSIONING.md`, `.kiro/steering/versioning.md`, `pyproject.toml`, `package.json`).
