# 0.5.4 (2026-05-14)

Acciones rápidas de IA en el chat, panel redimensionable y mejoras en el panel de administración.

## ✨ Features

- Acciones rápidas predefinidas en el chat AI: Explicar, Mejorar UI, Mejorar Proceso y Reparar.
- Panel de chat redimensionable con persistencia del ancho por diagrama (localStorage + user_preferences).
- Panel admin: nuevas columnas "Uso de licencia" (proyectos + diagramas), "Modelos IA conectados" y "Último login".
- Tracking de `last_login_at` en usuarios (login normal y post-MFA).
- Bloqueo de solicitudes de explicación en el modal de mejora con redirección al chat AI.
- Exportación Excel del admin muestra "Uso de licencia" en formato legible (proyectos/diagramas).

## ♻️ Refactors

- Lógica de resize del panel de chat movida de `AIChatPanel` a `DiagramEditorPage` para mejor control del layout.
- Detección de modo de respuesta (`text` vs `code`) refactorizada para soportar preset actions.
- Parsing de respuesta AI condicionado al modo de respuesta (evita extracción de código en modo texto).

## ⬆️ Upgrades

- Imagen Docker base del backend actualizada de `python:3.12-slim-bookworm` a `python:3.12-slim-trixie`.

## 🌐 Translations

- Internacionalización de textos hardcodeados en ChatInput (botón enviar, selector de modelo, etiqueta "Recomendado").
- Nuevas claves i18n para acciones rápidas del chat en español e inglés.
- Nuevas claves i18n para columnas del panel admin (Uso de licencia, Modelos IA, Último login).
