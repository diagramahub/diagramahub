# 0.5.8 (2026-06-18)

Exportación SVG, rediseño del modal de exportación y correcciones de seguridad (XSS DOM + OpenSSL en contenedor).

## ✨ Features

- **Exportación SVG**: descarga tus diagramas como vectores escalables y limpios (Mermaid, PlantUML, D2, DBML). Formato ideal para incrustar en documentación/READMEs o seguir editándolos en herramientas vectoriales.

## 💅 Mejoras de UI

- Modal de exportación rediseñado: los formatos se muestran en una cuadrícula 2×2 de tarjetas (PNG, SVG, PDF, Markdown), las opciones de contenido se agrupan en una sección secundaria compacta y la descarga del código fuente pasa a un botón discreto al pie. El resultado es una interfaz mucho menos cargada.

## 🔒 Seguridad

- **XSS basado en DOM (Snyk, Medium)**: el SVG renderizado ahora se sanitiza con DOMPurify (`sanitizeSvg`) antes de inyectarse vía `innerHTML` en la previsualización, el editor y la vista de diagramas compartidos. La salida de Mermaid (renderizada con `securityLevel: 'loose'`) se sanitiza igual que el SVG del servidor.
- Las descripciones Markdown renderizadas para PDF/PNG se sanitizan (`sanitizeRichHtml`) antes de asignarse vía `innerHTML`.
- La imagen Docker del frontend ahora ejecuta `apk upgrade` para incorporar los últimos parches de OpenSSL de Alpine (CVE-2026-* reportados por Snyk Container), igual que la imagen del backend.

## ♻️ Refactors

- El modal de exportación se extrajo a un componente dedicado `ExportDiagramModal`.
