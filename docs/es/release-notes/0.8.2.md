# 0.8.2 (2026-10-04)

Corrección del chat de IA: el diagrama que genera ahora **siempre** llega al cuadro de vista previa, en lugar de quedarse como código suelto en el chat. Además, el chat queda completo en inglés. Sin funciones nuevas ni migraciones.

## ⬆️ Notas de actualización

- Sin migraciones. Reconstruye las imágenes como siempre (`docker compose up -d --build`).
- Los mensajes que ya estaban guardados con el código suelto no cambian; las respuestas nuevas sí llegan con vista previa.

## 🤖 Chat de IA

- **El diagrama ya no se queda como código en el chat.** El chat adivinaba con palabras clave si el mensaje pedía un diagrama o hacía una pregunta, y solo buscaba el código en el primer caso. Pedidos como "¿Me puedes hacer…?", "Necesito que…", "Agrégale…", "resuélvelo" o "Diagrama de base de datos…" se tomaban como preguntas: el modelo sí respondía con el diagrama, pero se mostraba como texto partido en fragmentos, sin vista previa ni botón de aceptar, y había que copiarlo a mano al editor.
  - Ahora decide la respuesta del modelo: si trae el diagrama, se muestra con vista previa, se valida y se ofrece aceptar o rechazar. "Explicar" nunca genera vista previa.
  - Medido con Gemini real: 7 de 7 pedidos de ese tipo dejaban el código en el chat; ahora 0 de 7, en los 4 tipos de diagrama. Las preguntas siguen respondiéndose con texto.
- **Los diagramas grandes ya no llegan cortados.** Todas las respuestas del chat tienen el límite de 8.192 tokens (antes, las que parecían preguntas tenían menos y no se revisaba si se cortaban). Si una respuesta se corta, se muestra un aviso en lugar del fragmento.
- La detección inicial reconoce más formas de pedir cambios: ignora acentos y entiende verbos con pronombre ("agrégale", "hazlo", "corrígelo").

## 🌐 Idioma

- **El chat completo en inglés**: lista de mensajes, vista previa (Accept / Reject / Restore), selector de sesiones, hora relativa, fases ("Thinking…"), errores y conteo de mensajes con plurales correctos.
- Los errores del chat y de los proveedores de IA (sin créditos, llave inválida, modelo no disponible, límite de solicitudes) llegan en el idioma del usuario.
- La barra de estado del editor ("N líneas") y la comparación de la corrección con IA también se traducen.
