# 0.5.10 (2026-07-18)

Mejoras de navegación en el editor e información del proyecto, junto con una actualización de dependencias del frontend que deja el árbol de npm sin vulnerabilidades conocidas.

## ✨ Funcionalidades

- Se agregó un explorador de proyecto persistente, inspirado en VS Code, al editor de diagramas de escritorio.
- Ahora es posible crear diagramas directamente dentro de una carpeta, renombrar carpetas y mover diagramas entre la raíz del proyecto y las carpetas con arrastrar y soltar. Las carpetas continúan limitadas a un solo nivel.
- Se agregó la página **Acerca de** con detalles del producto, repositorio de GitHub, cuenta de X y correo de contacto.

## 🐛 Correcciones

- Las interacciones del explorador ya no cierran el panel como si fueran clics externos.
- Ajustar a pantalla ahora usa los límites del SVG renderizado y centra correctamente los diagramas D2.
- Se agregó el tipo faltante del elemento de lenguaje de Monaco en el registro de D2 para que el toolchain actualizado compile correctamente.

## ⬆️ Actualizaciones

- Se actualizaron parches compatibles del frontend: `axios 1.18.1`, `dompurify 3.4.12`, `mermaid 11.16.0`, `react-router-dom 7.18.1`, `vite 7.3.6`, `eslint 9.39.5`, `postcss 8.5.19`, `autoprefixer 10.5.4` y `typescript-eslint 8.64.0`.
- Se renovaron las dependencias transitivas del lockfile. `npm audit` ahora reporta **0 vulnerabilidades** en dependencias de producción y desarrollo.

## 📝 Documentación

- `CLAUDE.md` ahora apunta a `AGENTS.md` como fuente única de guía del proyecto.
