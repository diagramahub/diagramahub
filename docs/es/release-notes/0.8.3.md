# 0.8.3 (2026-10-11)

Corrección del sitio de documentación publicado y pulido de idioma en la interfaz: el sitio se construye con MkDocs Material, se eliminaron cadenas de interfaz sin traducir y los metadatos del documento ahora siguen el idioma activo. Sin migraciones ni funciones nuevas.

## ⬆️ Notas de actualización

- Sin migraciones. Reconstruye las imágenes como siempre (`docker compose up -d --build`).
- La configuración de GitHub Pages pasa de «Deploy from a branch: main /docs» a «GitHub Actions».

## 📚 Documentación

- **El sitio de documentación ya se ve como debe.** GitHub Pages publicaba la carpeta `docs/` con el tema por defecto de Jekyll: mostraba el Markdown crudo, sin navegación, sin buscador, sin temas ni selector de idioma, y `https://diagramahub.github.io/diagramahub/` respondía 404 porque no había página raíz.
  - Un flujo de GitHub Actions (`.github/workflows/docs.yml`) construye ahora el sitio con MkDocs Material y lo publica en Pages. Se agregó `site_url` (el sitio vive en el subdirectorio `/diagramahub/`), una portada en la raíz, el logo y el favicon del proyecto, y el selector de idioma apunta a las URLs correctas.
  - La interfaz de las páginas en inglés ya está en inglés (buscador, tabla de contenidos, navegación): Material solo admite un idioma de interfaz para todo el sitio y se resolvió con un override de tema por carpeta (`overrides/partials/language.html`).
  - `mkdocs build --strict` corre en cada push y en cada pull request, así que un enlace roto hace fallar la build en lugar de publicarse.
  - Se corrigieron los dos enlaces de las notas 0.5.9 que apuntaban fuera del directorio de documentación.

## 🌐 Idioma y accesibilidad

- **Sin cadenas de interfaz sueltas.** Alrededor de 40 textos visibles/audibles (tooltips, placeholders, `aria-label` y `alt`) estaban escritos a mano en los componentes, así que en inglés aparecían tooltips en español (y viceversa). Ahora pasan por `t()` con sus claves en `es.json` y `en.json`.
- **Controles de solo icono accesibles.** Los botones de zoom, tamaño de texto, pantalla completa y cierre ahora exponen `aria-label` además del `title`, para que los lectores de pantalla los anuncien.
- **Metadatos del documento coherentes.** `index.html` declaraba `<html lang="en">` con una interfaz por defecto en español. Ahora `<html lang>`, el `<title>` y la meta description siguen el idioma activo, y se agregaron `meta description` y `theme-color`.
