# 0.6.0 (2026-08-15)

Release mayor con conversión de diagramas entre tipos usando IA, nuevo tipo de diagrama de mano alzada (pizarrón blanco) con un modelo de interacción inspirado en Miro y Excalidraw, y migración a pnpm.

## ✨ Funcionalidades

- **Conversión de tipo de diagrama (IA)**: Permite convertir diagramas entre formatos Mermaid, PlantUML, D2 y DBML usando el proveedor de IA configurado. Incluye un modal de vista previa lado a lado con advertencias sobre posibles incompatibilidades antes de aplicar los cambios.
- **Tipo de diagrama Mano Alzada (Pizarrón)**: Nuevo tipo de diagrama "Freehand" que ofrece un lienzo similar a Excalidraw para dibujar diagramas con formas básicas (rectángulos, rombos, círculos), flechas, líneas, texto y trazos libres. Incluye barra de herramientas completa con selectores de color y grosor de trazo.
- **Mejora de usabilidad del lienzo freehand**: Se refinó el modelo de interacción tomando lo mejor de Miro y Excalidraw:
  - Deshacer/rehacer (Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y) con botones en la barra de herramientas e historial de hasta 100 pasos.
  - Edición de texto inline (sin prompt del navegador) con soporte multilínea, elementos de texto que crecen automáticamente y texto siempre centrado en las formas.
  - Atajos completos de herramientas (V/M/R/D/O/A/L/T/P/B), duplicar (Ctrl+D), mover con flechas del teclado y ajustar al contenido (F).
  - Herramienta mano y pan con Space+arrastre.
  - Resaltado al pasar el cursor y cursor de mover en modo selección.
  - Herramientas de alineación y distribución para selección múltiple.
  - Agrupar/desagrupar (Ctrl+G / Ctrl+Shift+G) con selección por grupo al hacer clic.
  - Rotación de formas y texto con manija de rotar y snap de 15° con Shift; las flechas conectadas siguen los anclajes rotados.
  - Guías de alineación rojas estilo Miro con snapping al arrastrar o dibujar.
  - Panel de estilos contextual junto a la selección.
  - Borrador con arrastre, líneas discontinuas, puntas de flecha al inicio/fin, esquinas redondeadas y control de tamaño de fuente.

## 🐛 Fixes

- El editor de diagramas ahora abre con el apartado de carpetas/archivos cerrado — solo aparece al hacer clic en el ícono de carpeta junto al nombre del diagrama.
- Los diagramas convertidos se recentran automáticamente (ajustar a pantalla) después de aceptar una conversión de tipo.

## ♻️ Refactors

- **Migración del gestor de paquetes frontend**: Se reemplazó npm por pnpm para instalaciones más rápidas y mejor eficiencia de disco. Se actualizaron Dockerfile, configuraciones de docker-compose, y se agregó `.npmrc` con configuraciones recomendadas.

## 🔧 Interno

- Se agregaron `build_convert_diagram_prompt` y `CONVERSION_SYSTEM_PROMPT` al módulo centralizado de prompts.
- Se creó `DiagramConversionService` siguiendo el patrón de servicios existente con dispatch abstracto de clientes IA.
- Endpoint backend `POST /api/v1/diagrams/convert` con semántica de solo-preview (sin auto-guardado).
- El estado del lienzo freehand se almacena como JSON en el campo `content` existente — sin necesidad de migración de esquema.
