# 0.6.0 (2026-07-30)

Release mayor con conversión de diagramas entre tipos usando IA, nuevo tipo de diagrama de mano alzada (pizarrón blanco), y migración a pnpm.

## ✨ Funcionalidades

- **Conversión de tipo de diagrama (IA)**: Permite convertir diagramas entre formatos Mermaid, PlantUML, D2 y DBML usando el proveedor de IA configurado. Incluye un modal de vista previa lado a lado con advertencias sobre posibles incompatibilidades antes de aplicar los cambios.
- **Tipo de diagrama Mano Alzada (Pizarrón)**: Nuevo tipo de diagrama "Freehand" que ofrece un lienzo similar a Excalidraw para dibujar diagramas con formas básicas (rectángulos, rombos, círculos), flechas, líneas, texto y trazos libres. Incluye barra de herramientas completa con selectores de color y grosor de trazo.

## ♻️ Refactors

- **Migración del gestor de paquetes frontend**: Se reemplazó npm por pnpm para instalaciones más rápidas y mejor eficiencia de disco. Se actualizaron Dockerfile, configuraciones de docker-compose, y se agregó `.npmrc` con configuraciones recomendadas.

## 🔧 Interno

- Se agregaron `build_convert_diagram_prompt` y `CONVERSION_SYSTEM_PROMPT` al módulo centralizado de prompts.
- Se creó `DiagramConversionService` siguiendo el patrón de servicios existente con dispatch abstracto de clientes IA.
- Endpoint backend `POST /api/v1/diagrams/convert` con semántica de solo-preview (sin auto-guardado).
- El estado del lienzo freehand se almacena como JSON en el campo `content` existente — sin necesidad de migración de esquema.
