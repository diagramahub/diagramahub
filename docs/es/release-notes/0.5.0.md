# 0.5.0 (2026-05-05)

Rediseño mayor de UX con sidebar colapsable, dark mode completo, soporte DBML, proveedor Minimax y mejoras significativas al chat de IA.

## ✨ Features

- Sidebar colapsable con navegación, toggle de tema y selector de idioma.
- Dark mode completo en toda la aplicación (modales, páginas, editor).
- Soporte para diagramas DBML (Database Markup Language) vía Kroki.
- Proveedor de IA Minimax (BYOL) con modelos MiniMax-M2.7 y MiniMax-M2.5.
- Página independiente de Proyectos con vista de tabla.
- Dashboard rediseñado: gráfico de dona, widget de uso de AI, diagramas recientes.
- Chat de IA: rolling summary persistente, formato código-primero, fallbacks de extracción.
- Editor: breadcrumb de proyecto, panel de código redimensionable, tema Kiro Dark para Monaco.
- Botón "Corregir con IA" en panel de código (errores de renderizado incluidos).
- Sección "Comunidad" en sidebar (próximamente).
- Modelos actualizados: DeepSeek v4, Gemini 3.1, MiniMax M2.7.
- `getEffectiveModel()` para fallback automático de modelos retirados.
- Contexto de renderizado Kroki en prompts de AI.
- `SENTRY_ENABLE_LOGS` configurable vía `.env`.

## 🐛 Fixes

- Monaco Editor no renderizaba código al abrir el panel.
- Toggle de código cerraba panel de descripción.
- Zoom persistido se sobreescribía por fit-to-screen al cargar.
- SVG de DBML con unidades `pt` no se mostraba.
- Crear nuevo diagrama no reseteaba estado del editor.
- `last_provider`/`last_model` no se guardaban en sesión de chat.
- Tags `<think>` de DeepSeek/MiniMax se mostraban en el chat.
- Marcador `<<<DIAGRAMA>>>` en español no se detectaba.

## ♻️ Refactors

- Logout movido del sidebar a la página de Perfil.
- Proyectos movidos a página independiente.
- "IA" renombrado a "Ajustes" con ícono de engrane.
- `max_tokens` incrementado de 2048 a 4096.
- Auto-retry desactivado para PlantUML/DBML.
- Tooltip usa `position: fixed` para evitar corte por overflow.
- Mensajes de error de Kroki parseados a formato amigable.

## 🔧 Internal

- Endpoint `/diagrams/recent` para diagramas recientes.
- Endpoint `/chat-sessions/stats/provider-usage` para estadísticas.
- `update_session_summary` en repositorio de sesiones.
- `diagram_type_counts` en respuesta de proyectos.
- `extract_fix_delimited()` para respuestas de fix DBML.
