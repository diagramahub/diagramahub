# 0.5.9 (2026-06-19)

Actualización de dependencias del frontend e imagen Docker de Node, limpieza de credenciales en tests y optimización del README — incluyendo varias correcciones de seguridad reportadas por Snyk.

## 🔒 Seguridad

- **dompurify** `3.4.2 → 3.4.11`: corrige Prototype Pollution, XSS, Trust Boundary Violation y Protection Mechanism Failure. Además se fija vía `overrides` para que la copia transitiva que incluye `monaco-editor` (`3.1.7`) también resuelva a `3.4.11`.
- **react-router-dom** `7.15.0 → 7.18.0`: corrige CSRF.
- **form-data** `4.0.5 → 4.0.6` (vía `overrides`, transitiva a través de axios): corrige CRLF Injection.
- Se eliminaron credenciales hardcodeadas en la suite de tests de Python (Snyk CWE-798). Los valores sensibles de ejemplo (passwords, tokens, secrets, API keys) ahora se generan dinámicamente con los helpers de `tests/utils/security.py`.

## 🐳 Imagen Docker

- Imagen base del frontend `node:20-alpine → node:24-alpine`. Node 20 llegó a fin de vida; Node 24 es **Active LTS** y se alinea con `@types/node` 24.

## ⬆️ Actualización de dependencias (sin breaking changes)

Refresh dentro de los majors actuales: `axios 1.18.0`, `react`/`react-dom 19.2.7`, `vite 7.3.5`, `@vitejs/plugin-react 5.2.0`, `tailwindcss 3.4.19`, `@tailwindcss/typography 0.5.20`, `postcss 8.5.15`, `autoprefixer 10.5.0`, `i18next 25.10.10`, `react-i18next 16.6.6`, `react-markdown 9.1.0`, `@sentry/react 9.47.1`, `eslint 9.39.4`, `typescript-eslint 8.61.1`, `@types/*` y otros.
