# 0.5.7 (2026-06-16)

Optimización del sistema de exportación de diagramas (PDF/PNG/Markdown) y auditoría de disponibilidad de modelos AI.

## ✨ Features

- Tamaño de exportación PDF reducido de 150–200 MB a ~1–5 MB usando rasterización PNG de alta calidad a 2x en lugar de captura de bitmap sin comprimir.
- La exportación Markdown ahora incluye la descripción del diagrama y los metadatos del proyecto cuando se seleccionan las opciones correspondientes.
- Las exportaciones PDF y PNG incluyen un encabezado con estilo corporativo: título del diagrama (siempre), info del proyecto/carpeta/autor (cuando se selecciona), y un pie de página con fecha de exportación y "Powered by Diagramahub".
- Las descripciones en PDF renderizan Markdown como HTML formateado (encabezados, negritas, listas, tablas, etc.) en lugar de mostrar la sintaxis Markdown cruda.
- Los botones de exportación muestran spinners de carga individuales por formato en vez de que todos cambien a "Exportando" simultáneamente.
- jsPDF ahora se carga bajo demanda para una carga inicial más rápida y una experiencia de exportación PDF más fluida.

- Lógica de exportación extraída de DiagramEditorPage.tsx a módulos utilitarios dedicados: ExportService, PDFGenerator, MarkdownExporter, DescriptionRenderer, MetadataHeader.
