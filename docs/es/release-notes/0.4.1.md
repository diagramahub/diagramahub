# 0.4.1 (2026-04-30)

Correcciones y mejoras de pulido sobre la versión 0.4.0.

## 🐛 Fixes

- Corrección del botón "Corregir con IA" para diagramas D2 y PlantUML: el parser de respuestas JSON de los proveedores de IA fallaba cuando el código corregido contenía llaves anidadas (sintaxis D2). Se implementó un parser robusto con balance de llaves (`extract_fix_json`) que reemplaza el regex greedy anterior en los 4 clientes (OpenAI, Claude, Gemini, DeepSeek).
- OpenAI ahora usa `response_format: {"type": "json_object"}` para forzar respuestas JSON válidas en correcciones de diagramas.
- Mejora de contraste del botón "Corregir con IA" en el editor de código oscuro: cambiado de `bg-purple-600` a `bg-purple-500` con sombra púrpura para mayor visibilidad.

## ✨ Features

- Fondo animado en la página de login: blobs flotantes con degradados rosa/púrpura y grid sutil de puntos, transmitiendo una estética moderna de IA. Componente reutilizable `AnimatedBackground`.
- Card de login con efecto glassmorphism (`backdrop-blur-lg`, borde semitransparente).
- Pantalla de verificación MFA ahora muestra el email del usuario al que se envió el código de verificación.

## 🌐 Translations

- Modal de compartir diagrama (`ShareDiagramModal`) completamente internacionalizado: 38 claves de traducción agregadas a `es.json` y `en.json` bajo la sección `sharing`.
- Formato de fecha en el modal de compartir ahora respeta el idioma activo (`es-ES` / `en-US`).
