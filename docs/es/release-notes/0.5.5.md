# 0.5.5 (2026-05-17)

Seguridad, Python 3.13, y limpieza de vulnerabilidades en tests y documentación.

## 🐛 Fixes

- Health check en `test-api.sh` corregido para validar `{"status":"ok"}` en vez de `"healthy"`.
- Script de onboarding (`test-onboarding.sh`) alineado con el flujo wizard (sin proyecto automático al registrarse).
- Ruta de mock `EmailService` corregida en `test_password_management.py` (apuntaba a `users.services` en vez de `integrations.email_service`).
- Mocks del adaptador Resend corregidos para usar `Emails.send_async` en vez de `Domains.list_async`.
- Límite de caracteres en descripciones de diagramas agregado (50,000) para mitigar riesgos de entrada grande.

## ♻️ Refactors

- Passwords hardcodeados en tests reemplazados por generación dinámica vía `generate_test_password()` y helpers en `scripts/test-helpers.sh`.
- `passlib` reemplazado por `bcrypt` directo para eliminar dependencia del módulo `crypt` (eliminado en Python 3.13).
- API keys de prueba en tests de Resend cambiadas a strings sin patrón de secreto real (`test-resend-api-key`).

## ⬆️ Upgrades

- Soporte para Python 3.13: constraint en `pyproject.toml` actualizado a `>=3.12,<3.14`.
- Imagen Docker base del backend actualizada a `python:3.13-slim-bookworm`.
- `bcrypt` actualizado de `4.0.1` a `^4.1` (compatible con Python 3.13).
- `passlib` eliminado de dependencias.
- Tooling (black, ruff, mypy) configurado para `py313`.

## 📝 Docs

- Ejemplos con passwords hardcodeados (`Password123`, `NewPassword456`, etc.) reemplazados por placeholders en `backend/README.md`, `INSTALL.md`, `deploy/`, `docs/`.
- Política de contraseña en `backend/README.md` actualizada (mínimo 12 caracteres + carácter especial).
- Estándar de calidad agregado en `CLAUDE.md`: no hardcodear credenciales en tests/scripts.
- Conexiones MongoDB de ejemplo cambiadas a formato con placeholders (`<db-user>:<db-password>`).
