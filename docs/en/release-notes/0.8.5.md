# 0.8.5 (2026-10-21)

Maintenance release: two frontend dependency advisories fixed, a sign-in error that was never shown, complete dark mode, the public shared page in English, and a frontend that passes lint with no errors or warnings. No new features.

## ⬆️ Upgrade notes

- Rebuild the images (`docker compose up -d --build`): frontend and backend dependencies changed.
- No migrations and no configuration changes.

## 🔒 Security

- **Frontend dependencies without known vulnerabilities.** `follow-redirects` 1.16.1 (two high advisories, used by axios) and `katex` 0.18 (prototype pollution, used by Mermaid for formulas). Mermaid 11 still asks for katex 0.16, so both are pinned with pnpm overrides; `pnpm audit --prod` is clean.

## 🔧 Fixes

- **Sign-in shows its error again.** With a wrong password (or MFA code) the page reloaded and the message never appeared: every 401 was treated as an expired session. The session is now closed only when there was one.
- **Dark mode everywhere.** 21 components and pages showed white panels in dark mode: confirmation, delete-folder, plan-limit, AI-provider, account, MFA and subscription dialogs, the AI chat previews, the shared diagram view, the access code form, password reset, MFA verification, the setup wizard and onboarding. Diagram canvases stay light, as in the editor, so diagrams stay readable.
- **Shared page in English.** The public shared diagram page, its access code form, the delete-folder dialog, confirmation dialogs and the show/hide password labels were always in Spanish.
- **Validation errors no longer break the screen.** When the server rejected a form with a list of errors, the page tried to render that list as the message; it now shows the translated generic message.
- **Account deletion as the sole admin.** The check that prevents the last admin from deleting the account read the role only when the page opened; it now follows it.

## 🔧 Internal

- Frontend lint: **0 errors, 0 warnings** (was 94 errors and 25 warnings). API errors are typed through a shared helper, the remaining `any` are typed, and each hook lists its dependencies or explains why the list is partial.
- Backend coverage floor raised from **45% to 60%**.
- Dependencies: dompurify 3.4.17, cryptography 50.0.2, python-multipart 0.0.32 and sentry-sdk 2.72.0. `poetry.lock` uses the Poetry 2 format the image already uses.

## 🧪 Tests

- Backend: **481 tests**, **65.26%** coverage (60% floor). Frontend: **31** Vitest tests, including the new API error helpers.
