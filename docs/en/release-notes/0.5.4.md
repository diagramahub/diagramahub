# 0.5.4 (2026-05-14)

AI quick actions in chat, resizable panel, and admin panel improvements.

## ✨ Features

- Preset quick actions in AI chat: Explain, Improve UI, Improve Process, and Fix.
- Resizable chat panel with per-diagram width persistence (localStorage + user_preferences).
- Admin panel: new columns "License Usage" (projects + diagrams), "AI Models" connected, and "Last Login".
- `last_login_at` tracking on users (normal login and post-MFA verification).
- Explanation requests blocked in the improve modal with redirect to AI chat.
- Admin Excel export shows "License Usage" in human-readable format (projects/diagrams).

## ♻️ Refactors

- Chat panel resize logic moved from `AIChatPanel` to `DiagramEditorPage` for better layout control.
- Response mode detection (`text` vs `code`) refactored to support preset actions.
- AI response parsing conditioned on response mode (avoids code extraction in text mode).

## ⬆️ Upgrades

- Backend Docker base image updated from `python:3.12-slim-bookworm` to `python:3.12-slim-trixie`.

## 🌐 Translations

- Hardcoded strings in ChatInput internationalized (send button, model selector, "Recommended" label).
- New i18n keys for chat quick actions in Spanish and English.
- New i18n keys for admin panel columns (License Usage, AI Models, Last Login).
