# 0.5.9 (2026-06-19)

Frontend dependency and Node Docker image refresh, test credential cleanup, and README optimization — including several security fixes reported by Snyk.

## 🔒 Security

- **dompurify** `3.4.2 → 3.4.11`: fixes Prototype Pollution, XSS, Trust Boundary Violation and Protection Mechanism Failure. Also pinned via `overrides` so the transitive copy bundled by `monaco-editor` (`3.1.7`) resolves to `3.4.11`.
- **react-router-dom** `7.15.0 → 7.18.0`: fixes CSRF.
- **form-data** `4.0.5 → 4.0.6` (via `overrides`, transitive through axios): fixes CRLF Injection.
- Removed hardcoded credentials from the Python test suite (Snyk CWE-798). Sensitive sample values (passwords, tokens, secrets, API keys) are now generated dynamically via the `tests/utils/security.py` helpers.

## 🐳 Docker image

- Frontend base image `node:20-alpine → node:24-alpine`. Node 20 reached end-of-life; Node 24 is **Active LTS** and aligns with `@types/node` 24.

## ⬆️ Dependency refresh (no breaking changes)

Within current majors: `axios 1.18.0`, `react`/`react-dom 19.2.7`, `vite 7.3.5`, `@vitejs/plugin-react 5.2.0`, `tailwindcss 3.4.19`, `@tailwindcss/typography 0.5.20`, `postcss 8.5.15`, `autoprefixer 10.5.0`, `i18next 25.10.10`, `react-i18next 16.6.6`, `react-markdown 9.1.0`, `@sentry/react 9.47.1`, `eslint 9.39.4`, `typescript-eslint 8.61.1`, `@types/*` and others.

## 📖 Documentation

- Slimmed down the README (~245 → ~130 lines): extracted detailed architecture into [ARCHITECTURE.md](../../../ARCHITECTURE.md) and security controls into [SECURITY.md](../../../SECURITY.md), condensed the feature list, and fixed broken header emojis.
