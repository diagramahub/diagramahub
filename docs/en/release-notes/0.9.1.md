# 0.9.1 (2026-11-22)

Maintenance release: the frontend image moves to nginx 1.31, fixing the nginx CVEs left as a known issue in 0.9.0, and pyotp is updated to 2.12.0. No new features and no user-visible changes.

## ⬆️ Upgrade notes

- Rebuild the images (`docker compose up -d --build`): the frontend base image and one backend dependency changed.
- No migrations or configuration changes. Existing MFA setups keep working.

## 🔒 Security

- **nginx 1.31 in the frontend image.** The base image moves from `nginxinc/nginx-unprivileged:1.30-alpine` to `1.31-alpine` (nginx 1.31.7). This fixes CVE-2026-113425, CVE-2026-121810, CVE-2026-123007, CVE-2026-123633, CVE-2026-118899 and CVE-2026-123634, the known issue of [0.9.0](0.9.0.md). The 1.30.7 image is still not published; the 1.31 series (mainline) is the one nginx recommends. The CI Trivy scan (CRITICAL/HIGH with a fix available) passes again with no findings. The nginx configuration is unchanged.

## 🔧 Internal

- **pyotp 2.12.0.** It now requires TOTP secrets of at least 112 bits and intervals of at most 120 s. DiagramaHub generates 160-bit secrets with 30 s intervals, so MFA on existing accounts is unchanged.
- The pending major upgrades (Stripe SDK 17, Tailwind CSS 4, Node 26, Python 3.15 and MongoDB 8.2) are left for 0.10.0. Stripe SDK 17 needs a migration: since v12, `current_period_end` lives on the subscription items, not on the subscription.

## 🧪 Tests

- Backend: **766 tests**, coverage **72.85%** (floor 60%), with pyotp 2.12.0. Frontend production image: build passing, no CRITICAL/HIGH Trivy findings and a start-up check (nginx 1.31.7 answers and applies the CSP). The frontend code did not change.
