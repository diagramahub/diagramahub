# 0.8.6 (2026-11-15)

Maintenance release: backend and frontend dependencies with security advisories updated, and the JWT library moves from `python-jose` to PyJWT. No new features and no user-visible changes.

## ⬆️ Upgrade notes

- Rebuild the images (`docker compose up -d --build`): frontend and backend dependencies changed.
- No migrations and no configuration changes. Open sessions stay valid: the token format does not change.

## 🔒 Security

- **New JWT library.** `python-jose` is replaced by PyJWT. `python-jose` has a critical algorithm-confusion advisory with no fixed release, and its `ecdsa` dependency another advisory with no fix. Neither was exploitable in DiagramaHub (our tokens use HS256 with the server secret and Google id_tokens were already restricted to RS256), but both packages leave the image. Google id_tokens are verified with the published key matching their `kid` and tolerate up to 60 s of clock difference with Google.
- **Backend dependencies.** certifi (critical: emSign root certificates with compromised intermediates), pillow 13 (used only to draw the MFA QR code), pymongo, urllib3, dnspython and pyasn1.
- **Frontend dependencies.** axios 1.21.1 with `follow-redirects` 1.16.3 (high, production), Vite 7.3.8 and Vitest 4.1.12 (development environment), and `source-map-js` and `postcss-selector-parser` (used by Tailwind 3). `pnpm audit --prod` is clean.

## 🔧 Internal

- Dependencies updated within their major version: React 19.3, React Router 7.18.5, DOMPurify 3.4.18, pydantic 2.14, sentry-sdk 2.75, resend 2.53, among others. Major upgrades (Mermaid 12, Vite 8, FastAPI, Stripe, Beanie 2…) are left for 0.9.
- New tests for Google id_token verification (audience, issuer, expiry, unknown `kid`, signature from another key and a forged HS256 token) and for our own tokens.
- Removed an unused component (`FixDiagramButton`); the "Fix with AI" button is still in the code panel.
- `brain-storm.md` marks each idea as implemented, partial or pending against the code.

## 🧪 Tests

- Backend: **495 tests**, coverage **65.68%** (floor 60%). Frontend: **31** Vitest tests; lint clean and production build passing.
