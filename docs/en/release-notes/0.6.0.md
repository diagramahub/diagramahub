# 0.6.0 (2026-07-30)

Major feature release introducing AI-powered diagram type conversion, a freehand whiteboard canvas, and migration to pnpm.

## ✨ Features

- **Diagram Type Conversion (AI-powered)**: Convert diagrams between Mermaid, PlantUML, D2, and DBML formats using your configured AI provider. Includes a side-by-side preview modal with warnings about potential incompatibilities before applying changes.
- **Freehand/Whiteboard Diagram Type**: New "Freehand" diagram type that provides an Excalidraw-like canvas for drawing diagrams with basic shapes (rectangles, diamonds, circles), arrows, lines, text, and freehand paths. Includes a full toolbar with color pickers and stroke width controls.

## ♻️ Refactors

- **Frontend package manager migration**: Replaced npm with pnpm for faster installs and better disk efficiency. Updated Dockerfile, docker-compose configurations, and added `.npmrc` with recommended settings.

## 🔧 Internal

- Added `build_convert_diagram_prompt` and `CONVERSION_SYSTEM_PROMPT` to the centralized prompts module.
- Created `DiagramConversionService` following the existing service pattern with abstract AI client dispatch.
- Backend `POST /api/v1/diagrams/convert` endpoint with preview-only semantics (no auto-save).
- Freehand canvas state stored as JSON in the existing `content` field — no schema migration needed.
