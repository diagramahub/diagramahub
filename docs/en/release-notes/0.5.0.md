# 0.5.0 (2026-05-05)

Major UX redesign with collapsible sidebar, full dark mode, DBML support, Minimax provider, and significant AI chat improvements.

## ✨ Features

- Collapsible sidebar with navigation, theme toggle, and language selector.
- Full dark mode support across all components, modals, and pages.
- DBML diagram support (Database Markup Language) via Kroki.
- Minimax AI provider (BYOL) with MiniMax-M2.7 and MiniMax-M2.5 models.
- Independent Projects page with table view.
- Redesigned dashboard: donut chart, AI usage widget, recent diagrams.
- AI Chat: persistent rolling summary, code-first format, extraction fallbacks.
- Editor: project breadcrumb, resizable code panel, Kiro Dark Monaco theme.
- "Fix with AI" button in code panel (works with render errors too).
- "Community" section in sidebar (coming soon).
- Updated models: DeepSeek v4, Gemini 3.1, MiniMax M2.7.
- `getEffectiveModel()` for automatic fallback on retired models.
- Kroki rendering context in AI prompts.
- `SENTRY_ENABLE_LOGS` configurable via `.env`.

## 🐛 Fixes

- Monaco Editor not rendering code when panel opens.
- Code toggle closing description panel.
- Persisted zoom overridden by fit-to-screen on load.
- DBML SVG with `pt` units not displaying.
- Creating new diagram not resetting editor state.
- `last_provider`/`last_model` not saved on chat session.
- `<think>` tags from DeepSeek/MiniMax showing in chat.
- Spanish `<<<DIAGRAMA>>>` marker not detected.

## ♻️ Refactors

- Logout moved from sidebar to Profile page.
- Projects moved to independent page.
- "AI" renamed to "Settings" with gear icon.
- `max_tokens` increased from 2048 to 4096.
- Auto-retry disabled for PlantUML/DBML.
- Tooltip uses `position: fixed` to prevent overflow clipping.
- Kroki error messages parsed to user-friendly format.

## 🔧 Internal

- `/diagrams/recent` endpoint for recent diagrams.
- `/chat-sessions/stats/provider-usage` endpoint for stats.
- `update_session_summary` repository method.
- `diagram_type_counts` in project response.
- `extract_fix_delimited()` for DBML fix responses.
