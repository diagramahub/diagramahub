# 0.4.0 (2026-04-28)

> ⚠️ **Version under construction** — This release is under active development. These notes document the changes included so far. More improvements will be added before the final version is closed.

Significant UX/UI improvements to the diagram editing view and overall platform responsiveness.

## ✨ Features

- **Project selector in editor**: clicking the project name in the breadcrumb opens a dropdown with all user projects, integrated search, and direct navigation without leaving the editing view.
- **Redesigned diagram panel**: the floating sidebar for navigating diagrams and folders now includes search, quick actions with icons and i18n, visual indicator for the active diagram (check + purple highlight), and folder hierarchy with vertical line.
- **IDE-style code editor**: the floating code panel now uses a dark theme (`vs-dark`), macOS-style title bar with window dots, file tab with error indicator, and bottom status bar with error info, line count, and diagram type.

## ♻️ Refactors

- **Full responsiveness**: all main views adapted for mobile and tablet:
    - **Diagram editor**: toolbar with `flex-wrap` into two rows on mobile, button text hidden (icons only), zoom controls hidden on mobile, floating panels go full-screen on mobile, compact status bar.
    - **Dashboard**: responsive padding and typography, compact "Create" button on mobile.
    - **Profile**: horizontally scrollable tabs, reduced card padding, sections stack vertically on mobile (profile photo, AI providers, admin users, plans).
    - **Shared view**: header with wrap, code and description panels go full-screen on mobile, zoom hidden on mobile (touch gestures available), compact footer.
    - **Navbar**: usage badge hidden on mobile.
- `CodeEditor` component extended with `borderless` and `theme` props for flexible integration in different contexts.
- CSS utility `.scrollbar-hide` added for invisible scrollbar with scroll functionality.

## 🌐 Translations

- New i18n keys (es/en): `breadcrumb.switchProject`, `breadcrumb.searchProjects`, `breadcrumb.noProjectsFound`, `editor.searchDiagrams`, `editor.noSearchResults`, `editor.deleteDiagram`, `editor.deleteFolder`, `editor.editFolder`, `editor.newDiagramInFolder`, `editor.syntaxError`, `editor.noErrors`, `editor.lines`, `editor.fixing`, `editor.fixWithAI`, `editor.fix`, `editor.copied`, `editor.copyCode`.
- Hardcoded strings replaced with `t()` keys in the code panel and diagram sidebar.
