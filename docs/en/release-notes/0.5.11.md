# 0.5.11 (2026-07-19)

Security and reproducibility improvements, plus clearer admin usage information and release visibility in the application.

## ✨ Features

- The admin user management table now shows every user's diagrams grouped by engine: Mermaid, PlantUML, D2, and DBML.
- The About page displays the running application version and provides a direct link to the GitHub releases page.

## ⬆️ Upgrades

- Added the versioned backend `poetry.lock` file and updated the Docker build to install locked dependencies.
- Updated the backend base image to Python 3.13 on Alpine 3.23.
- Pinned documentation dependencies to reproducible versions and updated documentation installation commands.

## 🔒 Security

- Updated `cryptography` to 46.0.7, `gunicorn` to 23.0.0, and `python-multipart` to 0.0.31.
