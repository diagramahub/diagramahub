# 0.4.1 (2026-04-30)

Bug fixes and polish improvements over version 0.4.0.

## 🐛 Fixes

- Fixed "Fix with AI" button for D2 and PlantUML diagrams: the JSON response parser from AI providers failed when corrected code contained nested braces (D2 syntax). Implemented a robust balanced-braces parser (`extract_fix_json`) replacing the previous greedy regex across all 4 clients (OpenAI, Claude, Gemini, DeepSeek).
- OpenAI now uses `response_format: {"type": "json_object"}` to enforce valid JSON responses in diagram fix operations.
- Improved contrast of the "Fix with AI" button in the dark code editor: changed from `bg-purple-600` to `bg-purple-500` with purple shadow for better visibility.

## ✨ Features

- Animated background on the login page: floating blobs with pink/purple gradients and a subtle dot grid, conveying a modern AI aesthetic. Reusable `AnimatedBackground` component.
- Login card with glassmorphism effect (`backdrop-blur-lg`, semi-transparent border).
- MFA verification screen now displays the user's email address where the verification code was sent.

## 🌐 Translations

- Share diagram modal (`ShareDiagramModal`) fully internationalized: 38 translation keys added to `es.json` and `en.json` under the `sharing` section.
- Date formatting in the share modal now respects the active language (`es-ES` / `en-US`).
