# 0.5.10 (2026-07-18)

Editor navigation and project information improvements, plus a frontend dependency refresh that leaves the npm dependency tree free of known vulnerabilities.

## ✨ Features

- Added a persistent, VS Code-inspired project explorer to the desktop diagram editor.
- Create diagrams directly inside a folder, rename folders, and move diagrams between the project root and folders with drag and drop. Folders remain limited to one level.
- Added an **About** page with product details, the GitHub repository, X account, and contact email.

## 🐛 Fixes

- Explorer interactions no longer close the panel as outside clicks.
- Fit to screen now uses the rendered SVG bounds and correctly centers D2 diagrams.
- Added the missing Monaco language item type in the D2 language registration so the refreshed toolchain compiles cleanly.

## ⬆️ Upgrades

- Updated compatible frontend patches: `axios 1.18.1`, `dompurify 3.4.12`, `mermaid 11.16.0`, `react-router-dom 7.18.1`, `vite 7.3.6`, `eslint 9.39.5`, `postcss 8.5.19`, `autoprefixer 10.5.4`, and `typescript-eslint 8.64.0`.
- Refreshed transitive dependencies in the lockfile. `npm audit` now reports **0 vulnerabilities** across production and development dependencies.

## 📝 Docs

- `CLAUDE.md` now points to `AGENTS.md` as the single source of project guidance.
