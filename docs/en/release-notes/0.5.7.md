# 0.5.7 (2026-06-16)

Optimized diagram export system (PDF/PNG/Markdown) and AI model availability audit.

## ✨ Features

- PDF export file size reduced from 150–200 MB to ~1–5 MB using high-quality 2x PNG rasterization instead of uncompressed bitmap capture.
- Markdown export now includes diagram description and project metadata when the corresponding options are selected.
- PDF and PNG exports include a corporate-styled header with diagram title (always), project/folder/author info (when selected), and a footer with export date and "Powered by Diagramahub" branding.
- PDF description sections render Markdown as formatted HTML (headings, bold, lists, tables, etc.) instead of showing raw Markdown syntax.
- Export buttons show individual loading spinners per format instead of all buttons changing to "Exporting" simultaneously.
- jsPDF is now lazy-loaded for faster initial page load and smoother PDF export experience.

## ♻️ Refactors

- Export logic extracted from DiagramEditorPage.tsx into dedicated utility modules: ExportService, PDFGenerator, MarkdownExporter, DescriptionRenderer, MetadataHeader.
- Export state management changed from single boolean to per-format tracking for cleaner UX.
