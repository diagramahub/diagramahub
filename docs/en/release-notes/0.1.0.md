# 0.1.0 (2026-04-16)

First functional release of DiagramaHub. Includes all base platform features.

## ✨ Features

- Diagram editor with Monaco Editor (syntax highlighting and autocomplete).
- **Mermaid** and **PlantUML** support with real-time rendering.
- Built-in syntax validation.
- Export to PNG, PDF, and Markdown.
- Per-diagram visual configuration: themes, layout engines, styles, and curves (Mermaid); themes and skinparam (PlantUML).
- Configurable background: color and pattern (plain, dots, grid).
- Viewport state persistence (zoom, x/y position) per diagram.
- Full-screen presentation mode with annotations.
- Full **project** CRUD.
- Full **folder** CRUD within projects.
- Hierarchical navigation: projects → folders → diagrams.
- BYOL model (Bring Your Own LLM): users configure their own API keys.
- Supported AI providers: **Google Gemini**, **OpenAI GPT**, **Anthropic Claude**, **DeepSeek**.
- Diagram generation from natural language descriptions.
- Existing diagram improvement with AI suggestions and diff preview.
- Automatic syntax error correction with explanation and diff.
- Automatic description generation for diagrams.
- Test endpoint to validate API keys before saving.
- API keys stored encrypted in the database and returned masked in API responses.
- Per-diagram provider/model preferences.
- Tracking of `generation_time`, `provider_used`, and `model_used` on every operation.
- Iterative chat sessions for step-by-step diagram refinement.
- Full prompt history — searchable and reusable.
- Shared links with unique tokens.
- Two access types for links: **public** and **protected** (access code of 4–20 characters).
- Link expiration options: 5, 10, 30 days, or unlimited.
- `allow_copy_code` flag to control whether visitors can copy the source code.
- Rate limiting and access logging with hashed IPs.
- User registration with password validation (minimum 8 characters, uppercase, lowercase, digit).
- JWT login (configurable tokens).
- Password reset flow with single-use tokens (1 hour expiration).
- Authenticated password change.
- Account deletion with confirmation phrase.
- Two roles: `admin` and `user`.
- Plan system with resource limits (`max_projects`, `max_diagrams`; `-1` = unlimited).
- Free plan (`FREE`) included.
- **Stripe** integration: checkout sessions, idempotent webhooks, billing portal.
- Multi-currency support via `prices` dictionary on plans.
- Billing history with links to Stripe PDFs and invoices.
- Provider-agnostic payment gateway pattern (Conekta as placeholder).
- **Multi-language**: Spanish (default) and English, with i18next.
- Profile management: timezone, language, avatar, security settings.
- Initial setup wizard and new-user onboarding.
- Admin panel for email vendor configuration (Resend).

## 📝 Docs

- Documentation with MkDocs Material (Spanish and English).
- Detailed installation guide.
- Stripe configuration quickstart.

## 🔧 Internal

- Full deployment via **Docker Compose**.
- Two deploy modes: `deploy/local-full/` (includes MongoDB 8) and `deploy/external-mongodb/`.
- One-line automatic installer (`install.sh`).
- Hot reload in development: backend (uvicorn `--reload`), frontend (Vite HMR).
- Post-installation verification and API test scripts.
- **Backend**: Python 3.11+, FastAPI, MongoDB (Beanie ODM), Pydantic v2, Poetry.
- **Frontend**: React 19, TypeScript, Vite 7, TailwindCSS v3, React Router v7.
- **Testing**: pytest, pytest-asyncio, pytest-cov, Hypothesis, Faker.
- **Quality**: Ruff, Black, mypy, ESLint.
