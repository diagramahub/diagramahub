# 0.9.2 (2026-11-26)

A release focused on the [freehand whiteboard](../guide/whiteboard.md), which grows from a sketching canvas into a full whiteboard. It is smoother with large scenes and works with touch screens and pens. It adds sticky notes, images, copy and paste between diagrams, and Miro-style connectors. It can also turn a section of the sketch into Mermaid, PlantUML or D2, exactly or with AI. The release also brings security fixes, up-to-date dependencies and a more reliable dev environment.

## ⬆️ Upgrade notes

- Rebuild the images (`docker compose up -d --build`): the frontend, the backend and their dependencies changed.
- No migrations. Whiteboard images are stored in a new collection (`diagram_files`), created on first use.
- There are two new optional variables: `DIAGRAM_FILE_MAX_BYTES` (3 MB per image) and `DIAGRAM_FILES_MAX_PER_DIAGRAM` (100 images per whiteboard). See [Configuration](../self-host/configuration.md).
- If you add another OAuth provider, add its domain to `OAUTH_AUTHORIZE_DOMAINS` (`frontend/src/utils/externalUrl.ts`). The browser now only follows payment and sign-in URLs on known domains.

## ✨ Features

- **A smoother whiteboard.**
    - The canvas paints once per frame and skips elements outside the view. Strokes use every pointer sample. Undo no longer copies the whole scene.
    - Whiteboards no longer load the code editor, which re-read the whole scene on every change.
    - Measured with 3000 elements and the CPU slowed down 4 times:

        | Metric | Before | Now |
        |---|---|---|
        | Longest freezes | 4–8 s | under 0.5 s |
        | Memory | 650 MB | 95 MB |
        | Paint time (median) | ~20 ms | ~2 ms |

- **Touch screens and pens.** One finger draws with the active tool. Two fingers pan and pinch to zoom. A double tap works like a double click. A stroke or drag that leaves the canvas is no longer lost.
- **The view is saved apart.** Position and zoom are saved without re-saving the drawing and don't count as an edit, and the view after **Fit to content** (++f++) survives a reload.
- **Sticky notes** (tool ++n++):
    - a click drops a 200 × 200 note and a drag sizes it; it opens ready for typing;
    - there are six colours, and the text shrinks to fit the note;
    - arrows connect to them;
    - the exact conversion to Mermaid turns them into a flag-shaped node.
- **Text inside shapes.** The text of rectangles, diamonds, ellipses and notes wraps inside the shape, also while typing. ++enter++ edits the selected shape.
- **Images on the whiteboard.**
    - Paste them, drop them on the canvas or pick them with the **Image** button. PNG, JPEG, WebP and GIF are accepted; SVG is not.
    - Before uploading, the browser shrinks them to 2048 px and re-encodes them, which also drops their metadata.
    - They are stored apart from the drawing, keep their proportions and accept connected arrows.
    - They appear in PNG export, the shared view (public and protected), embed mode, presentations and the Community.
- **Copy and paste through the system clipboard.**
    - Elements travel between diagrams, tabs and windows; images go with their data and are stored in the target diagram.
    - Groups and connections among the copies are kept.
    - Text copied from another app is pasted as text.
- **Miro-style connectors.** A selected shape, note or image shows a dot next to each side. Dragging from one pulls out an arrow connected to both elements. A click without dragging creates nothing.
- **Convert a section of the sketch.** **Convert to diagram** (selection panel or right-click menu) and **Convert sketch…** open a dialog with:
    - a picture of what will be converted: the selection, with the arrows between its elements and whole groups, or the whole whiteboard;
    - the target type: Mermaid, PlantUML or D2;
    - the method, with the recommended one marked:
        - **Exact, no AI**: Mermaid only; before converting it says how many nodes and links come out and what is left out;
        - **With AI, from the picture**: sends the picture of the section together with its texts and links read from the canvas, so handwriting doesn't garble the labels.

    The result is previewed before the new diagram is created; the whiteboard doesn't change.
- **Project and folder ZIPs with images.** Export includes each image once, under `.files/`. Import restores them after checking their content, type and size; one that fails the check is skipped with a warning. Older ZIPs still import.

## 🔒 Security

- **Open redirects.** The browser no longer follows any URL the API returns. Checkout, the billing portal, invoices and Google sign-in are followed only if they are https on the expected domain, and invoices open with `noopener`. The `?next=` parameter rejects control characters and whitespace.
- **SVG sanitized right where it is written** in the project PDF, the Community thumbnails and viewer, and the shared view.
- **Kroki** rejects diagram types outside the list before building the request path.
- **Access codes** for protected links are generated with cryptographic randomness.
- **The AI chat** no longer shows the internal text of errors, which could reveal server or collection names. It shows a generic message and the detail stays in the server log.
- **Logs neutralize request data** (`log_safe`), so a line break in a value can no longer forge entries.
- **Docker base images:** they were already built with `apk upgrade`, which updates the packages with security advisories (brotli, expat, zlib, curl, openssl, libxml2, libxslt, musl). This release confirms it on the built images.

## 🐛 Fixes

- Finishing a text edit with ++enter++ reopened the editor.
- A note's colour, or an image's missing border, carried over to the next shape drawn.
- Choosing another tool left the selection active. The style panel covered what was being dragged and clipped its options on narrow screens.
- The reasons something is left out of the exact conversion read correctly in the singular.

## 🔧 Internal

- **Dev environment:** the frontend container mounts its whole folder. Single-file mounts kept serving old versions after a `git checkout`, and lint and two test files failed inside the container.
- **CodeQL maintenance alerts cleared:**
    - lookups that failed silently now log a warning;
    - unused imports and assignments and an obsolete manual script were removed;
    - tests no longer use `await` inside `assert`.
- Tests use secret generators instead of keys and passwords written in the code. `.env.example` uses placeholders in the Mongo URIs.
- New `diagram_files` backend module. Routes can set their own `Cache-Control`: images are cacheable and the rest stays `no-store`.
