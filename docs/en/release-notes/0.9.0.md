# 0.9.0 (2026-11-15)

Feature release: the Community portal, diagrams from an image, search in the content, embedding in other sites and QR codes, folder presentations, project PDFs, API tokens and prompt history. Plus major library upgrades on the backend and the frontend, CI with security audits and several security improvements.

## ⬆️ Upgrade notes

- Rebuild the images (`docker compose up -d --build`): dependencies, Dockerfiles and compose files changed.
- **Motor is gone**: the backend talks to MongoDB through PyMongo's async API. No data migration.
- **Content-Security-Policy on by default** in the production frontend image. If your deployment calls extra origins (a proxy, another API), add them with `CSP_CONNECT_SRC_EXTRA`; to diagnose, `CSP_ENABLED=false` turns it off.
- Compose files pin `yuzutech/kroki:0.36.0` and `mongo:8.0` (were `latest` and `8`).
- **Passwords**: new ones can't be longer than 72 bytes. Longer passwords set before keep working.
- **Mermaid 12**: Mermaid diagrams render with the ELK layout and the neo look. To also move existing diagrams' theme to the new default (`redux-color`), run `python -m scripts.migrate_mermaid12` (report only) and then with `--apply`. See [Maintenance](../self-host/maintenance.md#maintenance-scripts).

## ✨ Features

- **Community.** A portal to publish your diagrams (category, tags, a CC license or all rights reserved), browse other people's, star them, comment on them and fork them into your account. With reports and admin moderation. See [Community](../guide/community.md).
- **Diagram from an image.** In the chat, **From image** turns a whiteboard photo, a screenshot or a sketch (PNG, JPEG or WebP, up to 4 MB) into code of the current diagram's type, with optional instructions and a preview before applying. Works with Gemini, OpenAI and Claude.
- **Search in the content.** The explorer also finds diagrams by their code or description, with the matching fragment highlighted, and filters by type (MMD, PUML, D2, DBML, DRAW).
- **Embed in other sites and QR code.** A shared link can allow other sites to show it in an `<iframe>`; the share dialog gives the embed code and a downloadable QR code.
- **Present a folder or the whole project** as slides, from the keyboard.
- **PDF of a project or a folder**: a cover with contents and one page per diagram.
- **Personal API tokens** under **Settings → API tokens**, read-only or read and write, for scripts, CI or your own tools.
- **Prompt history** in the chat: search and reuse the prompts that produced a diagram.

## 🔒 Security

- **CI on GitHub Actions**: tests, lint, dependency audits (pip-audit and `pnpm audit`), Trivy image scans, CodeQL and Dependabot.
- **Wider audit log**: besides authentication, changes to AI providers, shared links, integrations, plans and API tokens are recorded.
- **Content-Security-Policy by default** in the frontend; only the `/embed/` view can be framed.
- **Encryption key rotation** (`AI_ENCRYPTION_KEY_PREVIOUS` and `scripts/rotate_encryption_key.py`). See [Maintenance](../self-host/maintenance.md#rotating-the-encryption-key).
- **72-byte password limit**, bcrypt's real limit.
- **Sentry** configured to keep sending no personal data.

## ⬆️ Major upgrades

- **Backend**: Beanie 2 (no Motor), FastAPI 0.163, uvicorn 0.54 with `uvicorn-worker`, gunicorn 27, httpx 0.28, qrcode 8, google-genai 3, bcrypt 5, pytest 9, mypy 2, ruff 0.17.
- **Frontend**: Vite 8, Vitest 5, TypeScript 6, ESLint 10, i18next 27, react-markdown 10, Sentry 11.
- **Mermaid 12** with its defaults: ELK layout, the Redux color theme and the neo look, plus the new themes (Redux, Neo and their dark variants) under **Appearance**. The chosen layout and look now actually apply (before, they never reached Mermaid).
- **Infrastructure**: nginx 1.30.
